# 个人工作台 (Personal Workbench) v2

本地优先的 Electron 桌面工作台，集成待办、日程、看板、便签与桌面通知。

## 功能
- 待办清单（优先级 / 延期 / 逾期提醒）
- 月度日程（工资发放日、个税扣缴申报截止、社保公积金缴纳等「薪酬节点」一键导入）
- 看板（Todo / Doing / Done）
- 便签 & 主题切换
- 启动桌面通知（逾期任务、今日日程）

## 运行
```bash
npm install electron --save-dev   # 需先安装 Electron
npm start
```
> 启动脚本 `启动工作台-优化版.bat` 默认调用同级 `personal-workbench\node_modules\electron` 下的 `electron.exe`，可按本地环境调整路径。

## 数据存储
用户数据保存在 `%APPDATA%/personal-workbench-optimized/data.json`，不随仓库分发。

## 数据语义与保存保护（1.0.6）

完成会记录完成时间和工作事件；恢复完成是明确重新打开任务。归档由 archived / archivedAt 独立表示，只影响日常列表展示，取消归档保留原任务状态、完成时间和工作事件。删除移除任务并保留历史事件，界面提供撤销。项目历史名在事件产生时保存 projectNameAtEvent；旧记录缺失名称时明确标注，不能把当前项目名冒充历史名。旧归档的未知时间、已丢失且没有可靠事件佐证的完成时间不补造。

保存时验证关键数组、检测磁盘外部修改；从有内容变成全空需要针对当前快照的明确确认。确认导入全空内容仍受此保护。加载失败拒绝普通保存。每天首次改写、schema 迁移及全空改写前，原字节备份到 userData/backups；备份失败停止保存。仅清理本程序命名的滚动备份，最多 14 份且目标总量不超过 128 MiB，始终保留最新一份；历史导入前备份不参与自动清理。保存失败只清理本次新建的临时文件。备份不是跨设备备份，请继续定期导出。
